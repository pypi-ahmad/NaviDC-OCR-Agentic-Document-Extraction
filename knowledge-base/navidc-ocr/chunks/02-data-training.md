# Data engine and training

Data construction uses multi-node consensus pseudo-labels, deformation-aware synthesis, and rendered image-to-image self-verification. Four training stages add alignment, deformation awareness, content-structure decoupling, and GRPO. Table structure retains OTSL syntax without cell content; formula structure comes from LaTeX syntax. Rewards use NED for text, TEDS for tables, and CDM for formulas.
